# screenshot-redact

截圖和 PDF 分享前，一鍵遮蔽敏感資訊。純瀏覽器執行，檔案不離開你的電腦。

## 功能

**遮蔽方式**
- 模糊（blur）— 可調整強度
- 填色 — 六種預設色 + 自訂顏色

**支援格式**
- 圖片：PNG / JPG / WebP
- PDF：多頁逐頁標記，輸出圖片型 PDF（真正遮蔽，底層無資料）

**圖片 / PDF 來源**
- 拖曳到頁面
- 貼上（Ctrl+V）— 截圖工具直接貼
- 點選上傳

**PDF 特有功能**
- 有密碼保護的 PDF：自動提示輸入密碼解鎖
- 輸出 PDF 可選擇加上新密碼保護
- 每頁獨立標記遮蔽區域

**其他**
- 每頁支援多個遮蔽區域疊加
- 撤銷最後一個區域
- 下載圖片為 PNG 或 JPG

## 使用方式

1. 開啟 `screenshot-redact.html`（直接雙擊，不需伺服器）
2. 載入截圖或 PDF
3. 在圖片上拖曳框出要遮蔽的區域
4. PDF 可切換頁面，每頁分別標記
5. 下載遮蔽後的檔案

## 隱私

所有處理在瀏覽器本機完成。檔案不會上傳到任何伺服器。

無後端 · 無資料庫 · 無 Cookie · 無追蹤 · 離線可用（首次載入需下載 pdf.js / pdf-lib）
