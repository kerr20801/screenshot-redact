# screenshot-redact

截圖分享前，一鍵遮蔽敏感資訊。純瀏覽器執行，圖片不離開你的電腦。

## 功能

**遮蔽方式**
- 模糊（blur）— 可調整強度
- 填色 — 六種預設色 + 自訂顏色

**圖片來源**
- 拖曳圖片到頁面
- 貼上（Ctrl+V）— 直接從截圖工具貼
- 點選上傳（PNG / JPG / WebP）

**其他**
- 支援多個遮蔽區域疊加
- 撤銷最後一個區域
- 下載為 PNG 或 JPG（可調整品質）

## 使用方式

1. 開啟 `screenshot-redact.html`（直接雙擊，不需伺服器）
2. 載入截圖（拖曳 / 貼上 / 上傳）
3. 在圖片上拖曳框出要遮蔽的區域
4. 下載遮蔽後的圖片

## 隱私

所有處理在瀏覽器本機完成。圖片不會上傳到任何伺服器。

無後端 · 無資料庫 · 無 Cookie · 無追蹤 · 離線可用
